###执行情况
先递进后递归(反正就是有个堆栈的思想，在递归中，每次调用 rev 都会在栈上开辟一块全新的局部存储，每一层的 next 都是独立的内存变量，互不相干。)
```
#include<stdio.h>
void rev(int n){
    char next;
    if (n==1){
        next= getchar();
        putchar(next);
    }else{
        next= getchar();
        rev(n-1);
        putchar(next);
    }
}
int main(){ 
    int n = 5;
    rev (n);
    return 0;
}
```
